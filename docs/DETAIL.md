# 全部会话（sessions-window）

像「上下文洞察」一样在右侧打开一个浮动窗口，列出**所有**会话：

- 按**更新时间倒序**排列，展示标题、所属工作区、相对/绝对更新时间、工作目录、会话 ID。
- **搜索**：按标题 / 会话 ID / 路径 / 工作区名过滤。
- **分页**：默认每页 20 条，下拉可改 10 / 20 / 50 / 100，偏好会记住。
- **归档标识**：已归档会话带「已归档」徽标，点击**不跳转**；普通会话点击直达该对话。
- **工作区过滤列表**：工具栏「过滤」按钮展开面板，可把某些工作区下的全部会话整组隐藏（输入框 placeholder 默认显示「记忆中枢」，也可从现有工作区一键添加）；过滤列表持久保存。

入口有两个：输入框 dock 上的「会话」按钮（浮动窗口打开），以及右侧栏引导页里的「全部会话」卡片。

数据来自客户端官方会话/工作区快照，与官方侧栏同一份事实，不经过 Host。
